# Con fallos
```html
<html>
<head>
<title>Mi tienda de gadgets
</head>
<body>
<h1>Ofertas de otoño</h2>
<p>Auriculares con <b>cancelación de ruido</p></b>
</body>
</html>
```

## Los fallos

1. Falta \<!DOCTYPE html> al principio del documento.
2. Falta el atributo lang en \<html>
3. Falta \<meta charset="UTF-8"> en el \<head>.
4. Etiqueta de cierre incorrecta: \<h1> se cierra con \</h2> y deberia de ser con \</h1>
5. \<b> se abre dentro de \<p> pero se cierra después de \</p>

# Sin fallos
```html
<!DOCTYPE html>
<html lang="es">
<head>
<meta charset="UTF-8">
<title>Mi tienda de gadgets</title>
</head>
<body>
<h1>Ofertas de otoño</h1>
<p>Auriculares con <b>cancelación de ruido</b></p>
</body>
</html>
```
