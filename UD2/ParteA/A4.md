# Estilos rotos
```html
<h1 style="color:red font-size:40px;">Directo esta noche</h1>
<p style="text-align=center;">Estreno de temporada</p>
<p style="background-color:yellow;">Sorteo de una tarjeta gráfica<p>
```
## Fallos
En la primera linea falta el ";" que separa el color del tamaño de la fuente

En la segunda linea indica la alineacion con un "=" y deberia de ser con ":"

En la tercera le falta agregar "/" al cierre de "\<p>"

# Estilos arreglados
```html
<h1 style="color:red; font-size:40px;">Directo esta noche</h1>
<p style="text-align:center;">Estreno de temporada</p>
<p style="background-color:yellow;">Sorteo de una tarjeta gráfica</p>
```
