Elemento | Descripción
--------- | ---------
src      | D. Ruta del archivo de imagen
alt      | G. Texto que se muestra si la imagen no carga
href     | B. Indica el destino del enlace
target   | F. Indica dónde se abrirá el destino del enlace
id       | A. Crea un marcador (bookmark) dentro de la página
float    | E. Propiedad CSS para que la imagen flote junto al texto
_blank   | C. Valor de target que abre una pestaña nueva
