# Sin corregir
```html
<!DOCTYPE html>
<html>
<head>
<meta charset="utf-8">
<title>Mi galería</title>
</head>
<body>
<h1>Mi viaje de fin de curso</h1>
<img>src="playa.jpg" alt="Playa al atardecer"</img>
<img src="monte.jpg" style="width=300px; height=200px;">
<a href=https://www.wikipedia.org target="_blank">Más información sobre el destino
</body>
</html>
```

## Errores
1. <html> no indica el idioma
2. En la primera imagen, src y alt están fuera de la etiqueta (<img>src=...)
3. <img> se cierra con </img>, pero es una etiqueta vacía
4. La segunda imagen no tiene alt
5. El valor de href no lleva comillas
6. El enlace <a> no se cierra


# Corregido
```html
<!DOCTYPE html>
<html lang="es">
<head>
<meta charset="utf-8">
<title>Mi galería</title>
</head>
<body>
<h1>Mi viaje de fin de curso</h1>
<img src="playa.jpg" alt="Playa al atardecer">
<img src="monte.jpg" alt="Vista del monte" width="300" height="200">
<a href="https://www.wikipedia.org" target="_blank">Más información sobre el destino</a>
</body>
</html>
```
